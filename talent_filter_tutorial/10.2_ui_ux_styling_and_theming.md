# 10.2 UI/UX: Styling and Theming

## Understanding the Visual Design

In this section, we'll explore the styling and theming of the Talent Filter application. The application uses the Bulma CSS framework with custom theming to create a cohesive visual design.

## Bulma CSS Framework

Talent Filter uses [Bulma](https://bulma.io/), a free, open-source CSS framework based on Flexbox. Bulma provides a set of ready-to-use components and utilities that make it easy to create responsive layouts.

Key features of Bulma used in the application:

- Grid system for responsive layouts
- Navigation components
- Form styling
- Card components
- Modals and notifications
- Utility classes for spacing, typography, and colors

## Theme Colors

The application uses a custom theme with purple as the primary color. The theme is defined in `theme.css`:

```css
/* theme.css */

/* Custom color variables */
:root {
    --primary: #6a0dad;
    --primary-light: #9b4dca;
    --primary-dark: #4a0080;
    --secondary: #f5f5f5;
    --accent: #ff9800;
    --text-dark: #333333;
    --text-light: #ffffff;
    --background: #f9f9f9;
    --card-background: #ffffff;
    --border-color: #e0e0e0;
    --success: #48c774;
    --warning: #ffdd57;
    --danger: #f14668;
    --info: #3298dc;
}

/* Override Bulma's primary color */
.button.is-primary {
    background-color: var(--primary);
}
.button.is-primary:hover {
    background-color: var(--primary-light);
}

.navbar {
    background-color: var(--primary);
}
.navbar-item, 
.navbar-link {
    color: var(--text-light);
}
.navbar-item:hover, 
.navbar-link:hover {
    background-color: var(--primary-dark) !important;
    color: var(--text-light) !important;
}
.navbar-dropdown {
    background-color: var(--card-background);
}
.navbar-dropdown .navbar-item {
    color: var(--text-dark);
}
.navbar-dropdown .navbar-item:hover {
    background-color: var(--secondary) !important;
    color: var(--text-dark) !important;
}

.tag.is-primary {
    background-color: var(--primary);
    color: var(--text-light);
}

.notification.is-primary {
    background-color: var(--primary);
    color: var(--text-light);
}

.progress.is-primary::-webkit-progress-value {
    background-color: var(--primary);
}
.progress.is-primary::-moz-progress-bar {
    background-color: var(--primary);
}
.progress.is-primary::-ms-fill {
    background-color: var(--primary);
}

.tabs li.is-active a {
    border-bottom-color: var(--primary);
    color: var(--primary);
}

/* Custom styling for app name */
.app-name {
    font-family: 'Cabin', sans-serif;
    font-weight: 600;
    font-size: 1.2rem;
}

/* Custom styling for taglines */
.tagline {
    font-family: 'Dancing Script', cursive;
    font-optical-sizing: auto;
    font-style: normal;
    font-size: 2rem;
    color: var(--primary);
}
```

## Typography

The application uses a combination of system fonts and Google Fonts:

### Base Typography

The base typography uses system fonts for better performance:

```css
body {
    font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Oxygen-Sans, Ubuntu, Cantarell, "Helvetica Neue", sans-serif;
    font-size: 16px;
    line-height: 1.5;
    color: var(--text-dark);
}
```

### Custom Fonts

For specific elements, the application uses Google Fonts:

1. **Cabin**: Used for the application name and headings
   ```css
   .app-name, .title {
       font-family: 'Cabin', sans-serif;
   }
   ```

2. **Dancing Script**: Used for taglines and decorative text
   ```css
   .tagline {
       font-family: 'Dancing Script', cursive;
       font-optical-sizing: auto;
       font-style: normal;
   }
   ```

## Dark Mode Considerations

While the current application doesn't implement dark mode, the CSS variables make it relatively easy to add:

```css
/* Light mode (default) */
:root {
    --primary: #6a0dad;
    --background: #f9f9f9;
    --card-background: #ffffff;
    --text-dark: #333333;
    --text-light: #ffffff;
    --border-color: #e0e0e0;
}

/* Dark mode */
@media (prefers-color-scheme: dark) {
    :root {
        --primary: #9b4dca;
        --background: #121212;
        --card-background: #1e1e1e;
        --text-dark: #e0e0e0;
        --text-light: #ffffff;
        --border-color: #333333;
    }
}
```
