# 10.3 UI/UX: Components

## Understanding UI Components

In this section, we'll explore the key UI components used in the Talent Filter application. These components create a consistent user experience and make the application more intuitive to use.

## Navigation Components

### Main Navigation

The main navigation is implemented in the `header.html` component:

```html
<nav class="navbar is-fixed-top" role="navigation" aria-label="main navigation">
    <div class="container">
        <div class="navbar-brand">
            <a class="navbar-item" href="{% url 'home' %}">
                <img src="{% static 'images/logo.png' %}" alt="Talent Filter Logo" width="28" height="28">
                <span class="ml-2 app-name">Talent Filter</span>
            </a>
            
            <a role="button" class="navbar-burger" aria-label="menu" aria-expanded="false" data-target="navbarMenu">
                <span aria-hidden="true"></span>
                <span aria-hidden="true"></span>
                <span aria-hidden="true"></span>
            </a>
        </div>
        
        <div id="navbarMenu" class="navbar-menu">
            <div class="navbar-start">
                <!-- Navigation links -->
            </div>
            
            <div class="navbar-end">
                <!-- User menu and notifications -->
            </div>
        </div>
    </div>
</nav>
```

The navigation adapts based on user type:

- **Recruiter Navigation**: Dashboard, My Jobs, Candidates, Shortlisted, AI Recommendations
- **Job Seeker Navigation**: Dashboard, Find Jobs, My Applications
- **Unauthenticated Navigation**: Home, About

### User Dropdown

The user dropdown provides access to user-specific actions:

```html
<div class="navbar-item has-dropdown is-hoverable">

                <span class="icon"><i class="fas fa-id-card"></i></span>
                <span>Profile</span>
            </a>
        {% elif user.usertype.is_recruiter %}
            <a class="navbar-item" href="{% url 'settings' %}">
                <span class="icon"><i class="fas fa-cog"></i></span>

            </a>

</div>
```

### Tag Input

The application includes a custom tag input component for entering multiple values:

```html
<div class="field">
    <label class="label">Skills Required</label>
    <div class="tag-input-container">
        <input type="hidden" name="skills_required" id="skills-input" value="{{ form.skills_required.value|default:'' }}">
        <div class="tag-input-field">
            <div class="tags-container">
                {% if form.skills_required.value %}
                    {% for skill in form.skills_required.value.split(',') %}
                        <span class="tag is-primary">
                            {{ skill }}
                            <button type="button" class="delete is-small"></button>
                        </span>
                    {% endfor %}
                {% endif %}
            </div>
            <input type="text" class="tag-input-field-input" placeholder="Type and press Enter to add">
        </div>
    </div>
    <p class="help">Enter skills separated by pressing Enter after each skill</p>
</div>
```

## Notification Components

### Flash Messages

Flash messages are displayed at the top of the page:

```html
{% if messages %}
    <div class="container mt-3">
        {% for message in messages %}
            <div class="notification is-{{ message.tags }} is-light">
                <button class="delete"></button>
                {{ message }}
            </div>
        {% endfor %}
    </div>
{% endif %}
```

### Notification Dropdown

The notification dropdown is implemented in the `notification_dropdown.html` component:

```html
<div class="navbar-item has-dropdown is-hoverable">
    <a class="navbar-link">
        <span class="icon">
            <i class="fas fa-bell"></i>
        </span>
        {% if unread_notification_count > 0 %}
        <span class="tag is-danger is-rounded notification-count">{{ unread_notification_count }}</span>
        {% endif %}
    </a>
    
    <div class="navbar-dropdown is-right">
        <div class="notification-header">
            <p class="has-text-weight-bold">Notifications</p>
            {% if unread_notification_count > 0 %}
            <a href="{% url 'mark_all_notifications_read' %}" class="mark-all-read">Mark all as read</a>
            {% endif %}
        </div>
        
        <div class="notification-list">
            {% if recent_notifications %}
                {% for notification in recent_notifications %}
                <a href="{% url 'mark_notification_read' notification.id %}" class="navbar-item notification-item">
                    <div class="notification-icon">
                        {% if notification.notification_type == 'application' %}
                            <span class="icon has-text-info"><i class="fas fa-file-alt"></i></span>
                        {% elif notification.notification_type == 'message' %}
                            <span class="icon has-text-success"><i class="fas fa-envelope"></i></span>
                        {% elif notification.notification_type == 'interview' %}
                            <span class="icon has-text-warning"><i class="fas fa-calendar-alt"></i></span>
                        {% elif notification.notification_type == 'job' %}
                            <span class="icon has-text-primary"><i class="fas fa-briefcase"></i></span>
                        {% else %}
                            <span class="icon has-text-grey"><i class="fas fa-info-circle"></i></span>
                        {% endif %}
                    </div>
                    <div class="notification-content">
                        <p class="notification-message">{{ notification.message }}</p>
                        <p class="notification-time">{{ notification.created_at|timesince }} ago</p>
                    </div>
                </a>
                {% endfor %}
                {% if unread_notification_count > 5 %}
                <a href="{% url 'notifications_list' %}" class="navbar-item view-all">
                    View all notifications
                </a>
                {% endif %}
            {% else %}
                <div class="navbar-item">
                    <p>No new notifications</p>
                </div>
            {% endif %}
        </div>
    </div>
</div>
```
